# OIBSIP Data Analytics – Task 1

## Exploratory Data Analysis on Retail Sales Data

### 📌 Project Overview

This project is completed as part of my **Data Analytics Internship at Oasis Infobyte (OIBSIP)**.

The project focuses on performing **Exploratory Data Analysis (EDA)** on a retail sales dataset to identify sales trends, customer behaviour, product performance, category-wise sales, profitability, and regional sales patterns.

### 🎯 Objective

The main objectives of this project are:

* Analyze retail sales data
* Understand monthly and quarterly sales trends
* Identify top-performing products and categories
* Analyze customer segments
* Compare regional sales performance
* Understand profitability
* Identify meaningful business insights
* Provide actionable business recommendations

### 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Ju
